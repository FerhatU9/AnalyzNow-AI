# Forecast Stability Between Premier League Seasons

This analysis compares historical walk-forward Poisson predictions between the 2024/25 and 2025/26 evaluation seasons. It does not alter the forecasting engine or fit new parameters.

## Inputs

- `outputs/epl_2024_25_evaluation.json`
- `outputs/epl_2025_26_evaluation.json`

Both are locally generated by `python -m football_intel backtest` and include an `individual_forecasts` journal. The importer stores historical results and source provenance outside Git by default. Do not publish raw data without reviewing the source rights.

## Reproduce

From the repository root:

```powershell
.\.venv\Scripts\python.exe -m pytest -q tests/test_model_drift.py
.\.venv\Scripts\python.exe scripts\evaluate_model_drift.py
```

The script writes `outputs/model_drift.json` with per-season, first/second-half, and monthly summaries. It uses the same unnormalized multiclass Brier score and log loss as `football_intel.backtest`. Smaller loss values indicate better probability forecasts.

## Interpretation

- Overall loss changes across seasons do **not** necessarily show model deterioration: opponent strength, promoted teams, scheduling, random results and match difficulty can differ.
- Observed outcome frequency minus average predicted probability shows directional bias, **not** full conditional calibration.
- Monthly samples can be small; use them for diagnostics, not strong generalizations.
- Neither the Elo nor the ensemble model is retrained, selected or tuned in this script. Keep the 2025/26 result as an independent test of the previously frozen settings.
- The output is descriptive. A model change needs a prospectively defined test and a later untouched evaluation period.
